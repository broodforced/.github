# Security Policy

Cicada and Tymbal are reconnaissance and security-research tooling for **authorized testing only**.
Use them against systems you own or have explicit written permission to test.

## Reporting a vulnerability

If you find a security issue in Cicada or Tymbal themselves (not in a scanned target), report it
responsibly:

- Open an issue in the relevant repo under [github.com/broodforced](https://github.com/broodforced),
  or
- Email the maintainer directly with a clear description and steps to reproduce.

Please do not disclose a vulnerability publicly before it is addressed.

## Expectations for anyone using these tools

- Only test what you are authorized to test.
- Verify findings manually before reporting them anywhere.
- Respect the rules of the bug-bounty programs you participate in.
